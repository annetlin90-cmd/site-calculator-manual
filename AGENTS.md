# Правила Codex для site-calculator

1. Проект — статический HTML/CSS/JavaScript. Не добавляй фреймворк, сборщик, backend или зависимости без предварительного согласования.
2. Перед исправлением изучи связанные файлы. Вноси минимальные изменения. Не переписывай компоненты целиком из-за локальной правки.
3. Соблюдай `DESIGN.md`, утверждённые русские названия услуг и базовые цены в `js/pricing.js`. Любые изменения ценообразования и содержания требуют согласования.
4. Не ломай текущий расчёт, мини-бриф, смену темы и адаптивность. После изменения проверяй связанные сценарии.
5. Не добавляй API-ключи, токены и личные данные в файлы или GitHub.
6. Разделяй факты проверки: код написан; статически проверен; протестирован запуском; проверен на опубликованном сайте. Не заявляй непроведённые тесты.
7. Не публикуй проект и не выполняй разрушительные операции без подтверждения пользователя.
8. По итогам задачи кратко перечисли изменённые файлы, результат тестов, известные ограничения и способ отката через Git.


## Версия 0.3 — 2026-10-24
Первый экран: равномерная сетка трёх плашек, фотополоса (временные изображения из пользовательского референса). Калькулятор: нет предустановленного типа сайта, масштаба, текстов или фотографий; расчёт появляется после выбора сайта. Формула оформлена овальными статичными элементами. Сохраняются существующие тарифы, работа прогресса и тема.
