# Локальный Manrope — отчёт

Дата: 06.11.2026.
Источник проекта: только прикреплённый `site-calculator-manual(1).zip`.
Источник шрифта: прикреплённый `Manrope-VariableFont_wght(1).ttf`; файл совпадает побайтно с `Manrope-VariableFont_wght.ttf` внутри прикреплённого `Manrope(1).zip`.

## Изменения

- `index.html`: удалены Google Fonts stylesheet и два preconnect; на их месте добавлена предварительная загрузка `fonts/Manrope-VariableFont_wght.woff` с `rel="preload"`, `as="font"`, `type="font/woff"`, `crossorigin`.
- `css/style.css`: перед существующим кодом добавлено одно правило `@font-face` для Manrope: `format('woff')`, `font-weight: 200 800`, `font-style: normal`, `font-display: swap`; путь относительно CSS — `../fonts/Manrope-VariableFont_wght.woff`.
- Добавлены `fonts/Manrope-VariableFont_wght.woff` и оригинальная лицензия `fonts/OFL.txt` из приложенного архива Google Fonts.
- Добавлен этот отчёт. Остальные документы проекта сохранены в исходном виде; их прежние упоминания Google Fonts относятся к предыдущему способу подключения. Текущее подключение описано здесь.

Существующий CSS после нового `@font-face` совпадает с исходным побайтно. HTML вне заменённого блока подключений совпадает с исходным побайтно; исходные переводы строк сохранены. JavaScript, изображения и остальные исходные файлы, включая содержимое `.git`, сохранены без изменений. Команды Git и подключения к GitHub не выполнялись. Сайт не публиковался.

## Фактические характеристики шрифта

- Manrope, версия 4.505; исходный формат TrueType, выходной контейнер WOFF.
- Вариативная ось `wght`: минимум 200, значение по умолчанию 200, максимум 800.
- Присутствуют `fvar`, `gvar` и другие исходные таблицы; при конвертации вариативность не удалена.
- Присутствуют все буквы русского алфавита, включая Ё/ё, и базовая латиница A–Z / a–z.
- Внутреннее название семейства в метаданных — `Manrope ExtraLight`; это название базового мастера вариативного файла. CSS объявляет семейство `Manrope` и реальный диапазон 200–800. Такое внутреннее название не означает, что этот файл ограничен весом 200.
- Лицензия SIL Open Font License 1.1 приложена без изменений.

В проекте используются веса 400 (обычный текст), 500 (текст мини-брифа), 600 (поясняющие плашки), 650 (дополнительные услуги), 700 (навигация и подписи), 750 (кнопки), 800 (главный заголовок, цены и акценты). Все входят в диапазон файла. Прежние значения `font-weight` не редактировались.

## Статические проверки

- Исходный TTF и выходной WOFF читаются FontTools; таблицы разбираются без ошибок.
- Набор таблиц, данные вариативности и записи названий сохранены. WOFF использует другую упаковку; порядок записей таблицы имён и контрольная сумма контейнера могут отличаться, содержимое названий сохранено.
- Контуры и ширины всех символов Unicode-карты сверены между TTF и WOFF на весах 200, 400, 500, 600, 650, 700, 750 и 800: совпадают.
- Пути preload и CSS ведут к одному существующему файлу.
- HTML5 и CSS разбираются без ошибок; оба JS-файла проходят `node --check`.
- В исполняемых HTML/CSS/JS нет ссылок на `fonts.googleapis.com` или `fonts.gstatic.com`.
- Из существующих файлов изменены только `index.html` и `css/style.css`.

## Проверка в браузере

Среда: headless Chromium 153.0.8010.0, локальный HTTP-сервер.

- Manrope загружается как пользовательский веб-шрифт; диапазон CSS FontFace — 200–800, статус `loaded`.
- Браузер подтверждает применение локального Manrope к русскоязычному главному заголовку; в вычисленных стилях заголовка остаётся вес 800.
- Проверена загрузка весов 400/500/600/650/700/750/800 с русским и латинским текстом.
- На одну холодную загрузку страницы приходится один запрос файла WOFF: preload повторно используется правилом CSS.
- В проверенных HTTP-запусках внешних запросов, в том числе к Google Fonts, нет.
- На ширинах 320, 390, 620, 621, 800 и 1200px в обеих темах горизонтального переполнения не обнаружено. Все четыре изображения загружаются.
- Проверены базовые цены всех пяти типов сайта, добавление опции, заполнение разделов, прогресс 100%, формирование мини-брифа с кириллицей и латиницей, закрытие диалога, сброс и сохранение темы после обновления.
- При прямом открытии `index.html` через `file://` локальный WOFF также загрузился; переполнения на 1200px нет.
- В проверенных HTTP-сценариях ошибок выполнения JavaScript не обнаружено.
- Контрольные снимки десктопной тёмной и мобильной светлой версии просмотрены. Полный попиксельный аудит относительно прежней сетевой версии не проводился.

## Скачок при первом открытии

Проведены шесть запусков в новых браузерных контекстах без прогретого кэша: по три при 1200 и 390px. При обычной скорости localhost в собранных кадрах главный заголовок уже использовал загруженный шрифт; перехода с запасного начертания и изменения геометрии текста в этих кадрах не обнаружено. Это результат конкретной тестовой среды, не гарантия для всех устройств и сетей.

Дополнительно файл шрифта намеренно задерживался сервером на 350мс. В этом режиме подтверждена подмена запасного шрифта на Manrope: в кадрах до загрузки использовался fallback, после загрузки менялась геометрия текста заголовка. На 1200px высота текстового диапазона изменилась примерно со 169 до 189px, на 390px — со 140 до 151px. Это измерение текстового диапазона, не CSS-размера шрифта.

Вывод: локальный файл и preload устраняют зависимость от загрузки Google Fonts, но выбранное по заданию `font-display: swap` сохраняет возможность подмены при задержке. Полное исчезновение исходного скачка на компьютере пользователя не подтверждено. Причина скачка в исходной сетевой версии отдельно не доказана; скорость относительно её реальной загрузки Google Fonts не измерялась.

## Ограничения и дальнейшая проверка

- Проверить первое открытие и обновление страницы в Edge пользователя с отключённым кэшем, затем на реальном телефоне.
- Поведение на опубликованном хостинге, HTTP-кэширование и другие браузерные движки не проверялись.
- Внешнее подключение раньше запрашивало веса 400/500/600/700/800; локальный вариативный файл также поддерживает реальные промежуточные 650/750. Значения CSS сохранены, но попиксельное совпадение со старым выбором начертаний Google Fonts не гарантируется.
- Подтверждать полное устранение скачка следует только после проверки на целевом устройстве. Дополнительные изменения типографики или стратегии `font-display` в эту задачу не включены.

## Установка и откат

Распаковать архив в новую отдельную папку; внутри сохранена папка `site-calculator-manual` и исходная структура с добавленной `fonts/`. Открыть её `index.html`. Установка в рабочую папку пользователя и публикация выполняются отдельно.

Исходный архив проекта не изменён. Для отката использовать исходную копию. Если позднее изменения будут перенесены в отдельный Git-коммит, откат возможен через `git revert` этого коммита после сохранения текущих правок; в рамках этой задачи коммит не создавался.
