# Site Calculator — учебный мини-сайт

Текущая версия: v0.5 (25.10.2026). Учебный прототип. Статический сайт с комбинированным калькулятором стоимости разработки сайта и мини-брифом.

## Состав
- `index.html` — структура страницы, вопросы, сводка, диалог результата.
- `css/style.css` — дизайн, адаптивность и две темы.
- `js/pricing.js` — пять типов услуг, базовые цены и условные дополнительные доплаты.
- `js/script.js` — выбор опций, расчёт, динамическая сводка, копирование и темы.
- `DESIGN.md` — визуальная система.
- `AGENTS.md` — правила для Codex.
- `images/` — четыре локальных изображения фотополосы.
- `CHANGELOG.md` — изменения v0.5, результаты проверок и ограничения.

## Запуск на Windows
1. Распаковать ZIP в отдельную папку `site-calculator`.
2. Дважды нажать на `index.html` — он откроется в браузере. Интернет нужен только для загрузки Manrope из Google Fonts. Копирование брифа по адресу `file://` может работать по-разному в браузерах; предусмотрена попытка резервного копирования.
3. При желании использовать VS Code + Live Server, либо Python 3: открыть терминал в папке сайта и выполнить `python -m http.server 8000`, затем открыть `http://localhost:8000`.

## Основные тесты для ручной проверки
1. Выбрать все пять типов сайтов — сумма должна начинаться с 15 / 35 / 35 / 45 / 60 тыс. ₽ соответственно.
2. Включить и выключить несколько дополнений — убедиться, что сумма изменяется один раз на каждую опцию.
3. Сменить тип сайта — выбранные дополнения другого типа должны сброситься.
4. Выбрать объём, тексты и изображения, добавить комментарий, нажать «Получить сводку» и проверить, что ответы попали в бриф.
5. Скопировать бриф, проверить буфер обмена. Если браузер блокирует копирование из локального файла — использовать localhost.
6. Переключить светлую и тёмную темы; перезагрузить страницу и убедиться, что тема сохранилась.
7. Проверить ширины 320, 375, 768, 1024 и 1440 px; отсутствие горизонтального скролла и доступность полей на мобильном.
8. Проверить управление клавиатурой, фокус, закрытие диалога по Escape.
9. Проверить консоль браузера на ошибки.

## Публикация
Пока проект НЕ опубликован. Для размещения подойдёт статический хостинг, например GitHub Pages. Перед публикацией пользователь согласовывает размещение. `index.html` должен оставаться в корне репозитория, все пути относительные. Собственный домен, backend и сборка не требуются.

## Важно
Все надбавки в `js/pricing.js` — демонстрационные, не реальное ценообразование. В базах включены только согласованные или явно обозначенные условные работы. Тарифы и тексты уточнять до коммерческого использования. Сайт не собирает заявки и не отправляет бриф на сервер. Google Fonts — внешний запрос; при недоступности применяется запасной шрифт.
